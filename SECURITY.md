# Security Policy

## Supported versions

Eve Insights is pre-release. Security fixes are applied to the latest published
version of `@eve-insights/reporter` and to `main`.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Email **jim@jimdrury.co.uk** with:

- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- any suggested fix

You can expect an acknowledgement within 72 hours and an assessment within
seven days. We will keep you updated while we work on a fix, and will credit
you in the release notes unless you would rather stay anonymous.

Please give us a reasonable opportunity to ship a fix before disclosing
publicly.
